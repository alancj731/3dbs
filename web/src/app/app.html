About this project

A full-stack SQL practice app: your query runs on a real database and is graded by comparing its result with a reference answer, on SQL Server, MySQL and PostgreSQL loaded with the same data.

Built with

Backend
C# / .NET 10 · ASP.NET Core minimal API · ADO.NET (SqlClient, MySqlConnector, Npgsql) · rate limiting · xUnit
Frontend
Angular (standalone components, signals) · CodeMirror 6 · TypeScript
Data & hosting
SQL Server 2022 · MySQL 8.4 · PostgreSQL 17 · Docker Compose · Caddy (HTTPS) · Vercel · GitHub Actions

Architecture

Browser ─► Angular app ─/api─► ASP.NET Core API ─► SQL Server
           (Vercel)              (Docker VM,       ├─► MySQL
                                  behind Caddy)    └─► PostgreSQL
  • SqlGuard tokenizes your SQL per dialect and allows only SELECT/WITH/INSERT/UPDATE/DELETE.
  • Runner executes it as a restricted login inside a transaction that is always rolled back.
  • Checker grades by result, not text: it runs the reference answer and diffs the rows.
